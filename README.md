# Tootsi 3PL Portal (demo)

Clickable demo of the 3PL receiving portal. Fake POs only.

Live: https://jmunevar-afk.github.io/tootsi-3pl-demo/

## Google Workspace version (free pilot)

- Preview: https://jmunevar-afk.github.io/tootsi-3pl-demo/workspace/ (3PL demo logins: transplus / demo-tp, deslauriers / demo-dl)
- Code (Apps Script): [`apps-script/`](apps-script/) · install guide: [`apps-script/INSTALL.md`](apps-script/INSTALL.md)

The preview runs the real Apps Script code in the browser with sample data. In the pilot the same code runs on Tootsi's Google account: a Sheet is the database and a Drive folder holds the photos.
